# Mohan Mahajan — Creative Engineering & Full-Stack Portfolio

Official portfolio of **Mohan Mahajan** — Creative Technologist, Full-Stack Engineer, and Problem Concierge. Built with React 19, TypeScript, Tailwind CSS, and Framer Motion, inspired by the high-velocity aesthetic of **Better Call Saul** and **Youjin Jeong's WHSP problem concierge**.

## ⚖️ Features & Architecture

- **Creative Problem Concierge & Case Dossiers**:
  - Asymmetric forensic dossier matrix featuring 5 Master Dockets: Classified Case Files, Technical Toolkit, Track Record & Honors, The Service Flow, and Capabilities & SLA.
  - Skeuomorphic legal Manila folder aesthetics, forensic badges, and stoichiometric code purity metrics.
- **Route 66 Billboard Ad**:
  - *"GOT BUGS? BETTER CALL MOHAN!"* featuring iconic Better Call Saul Albuquerque courthouse styling and 24/7 hotline dispatch.
- **Monumental Editorial Footer**:
  - Monumental Bodoni/Didone typography featuring **MOHAN MAHAJAN**.
  - Classical Baroque Courtroom Trial Assembly cutout creating a multi-plane Renaissance depth illusion.
  - Live Albuquerque, New Mexico Mountain Time (MST) status clock, availability telemetry, and confidential inquiry dispatch terminal.
- **Dynamic Persona Switching**:
  - Interactive multi-mode engine: `{ whsp }` Problem Concierge, `Saul Goodman` Creative Technologist, and `Jimmy McGill` Scrappy Builder.
- **Audio Experience**:
  - Integrated Better Call Saul OST soundtrack player with custom soundwave telemetry.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite (TypeScript)
- **Styling**: Tailwind CSS + Custom Design Tokens
- **Motion & Smooth Scroll**: Framer Motion + Lenis
- **Typography**: Bodoni Moda, DM Serif Display, Cormorant Garamond, IBM Plex Mono
- **Icons**: Lucide React
- **Audio**: Custom Web Audio context with interactive soundtrack stream

## 🚀 Getting Started

### 1. Installation

```bash
npm install
```

### 2. Local Development

```bash
npm run dev
```

### 3. Production Build

```bash
npm run build
```
